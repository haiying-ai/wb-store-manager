# WB 固定早间日报模板（扩展只读版）

所有早间日报必须按以下顺序输出。除非用户明确授权，日报只读：不得修改商品、价格、库存、广告、促销或买家消息。

1. **快照信息与口径**：抓取时间、上一有效早间快照、时区、滚动周期、比较规则及每个接口 HTTP 状态。
2. **店铺总览对比**：每项均列出“本次 / 上次 / 变化”：Content 卡、Analytics 漏斗卡、浏览、加购、订单、买退、收藏、卖家库存、WB 库存、可用 FBS 仓、广告活动、未回复评价/问题、近 7 天 FBS 订单。
3. **类目指标对比**：每类目一行，列出 Content 卡、Analytics 卡、浏览、加购、订单、收藏、卖家库存、WB 库存；单元格使用“本次（变化）”。
4. **重点 SKU 漏斗**：按加购排序，展示 SKU、nmID、浏览、加购、订单及变化；搜索栏目展示搜索进卡、搜索加购、搜索订单、平均/中位位置、返回/请求 SKU 数和 Top SKU。
5. **异常提醒**：仅列零/低库存、加购无订单、错误卡、价格读回异常、订单/库存/FBS 链路异常、未回复评价或问题；搜索报告未返回的 SKU 不得直接视为零。
6. **可行动机会**：优先加购无订单 SKU；建议只能是下一步可验证的只读动作。
7. **广告与促销状态**：有投放才展示 fullstats 的曝光、点击、花费、加购、订单、ROI；促销仅展示未来 7 天可关注活动，绝不自动报名。
8. **已验证事实 / 合理推断 / 待验证项**：严格分开。滚动窗口变化只能说明方向；权限、限流、HTTP 非 200 或口径不完整必须列为待验证。
9. **数据状态与产物**：列每个数据源 HTTP 状态、未执行的写操作、快照与报告绝对路径。

## 必采集的只读数据源

- Content 商品卡、Analytics 漏斗、搜索表现、FBS 仓
- 商品/分组历史、库存报告、价格读回、错误商品卡
- 未回复评价/问题、订单/销售明细、广告查询/统计、未来 7 天促销日历

接口不可用时保留栏目并标注 HTTP 状态和原因；不得把空值补零或省略。新增指标无有效基线时写“首次可比采集”。Analytics 限流必须节流。
